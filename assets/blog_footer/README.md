- 적용 범위: 모든 카테고리의 모든 게시물(수동 작성·예약 자동화·신규 게시·기존 게시물 수정)
- 게시 파일: `bychem_contact_banner.png`
- 네이버 표시 폭: 약 600~700px
- 링크: `https://bychem.com/`
- 위치: 한줄정리·관련 글 아래, AI 이미지 고지문이 있으면 그 고지문 바로 위
- 이미지 캡션: 사용하지 않음

`BYCHEM 뉴스`, `BYCHEM 인사이트`, `BYCHEM 솔루션`, `BYCHEM 시리즈` 등 카테고리를 이유로 배너를 생략하지 않는다. 사용자가 해당 게시물에서 CTA 제외를 명시적으로 요청한 경우에만 생략한다.

배너의 로고, 문구, 연락처와 주소를 임의로 수정하거나 매 회차 다시 생성하지 않는다.
