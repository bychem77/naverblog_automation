# 바이켐 블로그 이미지 생성용 캐릭터 활용 추가 프롬프트

이 문서는 바이켐 네이버 블로그의 썸네일·본문 이미지를 생성할 때 기존 문체·안전·보안 프롬프트에 추가하여 사용한다.

## 1. 기본 원칙

- 사용자가 제공한 바이켐 캐릭터·스티커 원본 이미지를 **캐릭터 정체성 참조 이미지**로 사용한다.
- 얼굴, 흰 양털, 갈색 말린 뿔, 체형과 비율, 안경·고글, 목도리·장갑 색을 임의로 바꾸지 않는다.
- 캐릭터를 실제 직원, 연구원, 고객, 현장 작업자 또는 제품 성능 보증 주체로 오인하게 표현하지 않는다.
- 정치·선정·혐오·갈등·사건사고·위험행동·과장된 경고 상황에 캐릭터를 사용하지 않는다.
- 한 이미지에는 원칙적으로 캐릭터 한 명만 사용하며 핵심 정보나 기술 구조를 가리지 않는다.
- 캐릭터가 들어간 이미지는 게시물당 보통 1~2컷 이내로 사용한다. `BYCHEM 인사이트`, `BYCHEM 솔루션`, `BYCHEM 시리즈` 대표사진에는 별도 요청이 없으면 캐릭터를 넣지 않고, 본문에서 필요한 장면에 활용한다.
- 캐릭터가 없는 기술 이미지도 충분히 사용한다. 모든 이미지에 캐릭터를 넣지 않는다.
- 새 게시물마다 래미가 실제 기술 장면에 자연스럽게 통합된 본문 이미지가 최소 1컷 있어야 한다. 네이버 스티커·이모티콘은 이 요건을 대신하지 못하며, 사용자가 캐릭터 제외를 명시한 경우만 예외로 한다.
- 색상과 역할을 바꿔 반복감을 줄이되 캐릭터 색상만 바꾸고 같은 배경·구도·행동을 반복하지 않는다.
- 기존 스티커의 문구를 새 이미지에 자동으로 복제하지 않는다. 문구가 필요하면 승인된 정확한 한글만 별도 입력하고 오탈자를 육안 검수한다.
- 인터넷에서 찾은 유사 캐릭터나 타사 캐릭터를 섞지 않는다.

### 네이버 스티커 사용

- 사용자가 제공한 네이버 스티커 원본은 게시물의 문맥과 감정에 맞을 때 본문에 직접 삽입할 수 있다.
- 스티커는 게시물당 1~2개를 기본으로 하며, 모든 소제목이나 문단마다 반복하지 않는다.
- 스티커는 본문 폭을 가득 채우지 않고 긴 변 기준 약 360~420px 또는 본문 폭의 35~50%로 축소해 사용한다.
- 기술 설명·수치·안전 안내를 가리지 않고 문단 사이의 여백 또는 마무리 부분에 가운데 정렬로 배치한다.
- 스티커 자체에 이미 문구가 있으므로 주변 본문에서 같은 문장을 반복하지 않는다.
- 스티커는 이미지 설명이 필요한 기술 이미지로 취급하지 않으며, 장식적 이미지임을 고려해 불필요하게 긴 설명을 붙이지 않는다.
- 스티커 앞뒤에는 빈 줄을 두어 본문과 시각적으로 붙지 않게 한다.
- 스티커에 포함된 승인된 문구와 캐릭터 외형은 수정하지 않는다.
- 스티커를 실제 제품·현장·성과 증빙 이미지처럼 사용하지 않는다.

## 2. 색상별 권장 역할

- **블루 레미:** 연구실 실험, 냉각, 첨단소재, 기술 원리 체험
- **그린 레미:** 산업현장 점검, 체크리스트, 소재 검토, 친환경·안전 확인
- **레드 레미:** 발표, 핵심 설명, 요약, 독자 안내

### 스티커별 권장 위치

- `안녕하세요`: 도입부 인사 또는 기업 소식의 시작
- `궁금해요`: 질문형 소제목이나 개념 소개 앞뒤
- `연구중`: 기술·소재·연구개발 설명 구간
- `꼼꼼하게`: 체크리스트, 품질, 소재 선정, 안전 검토 구간
- `좋아요`: 핵심 장점 또는 요약 뒤
- `쉿 비밀`: 일반 정보형 글에서는 가급적 사용하지 않고 보안·오해 소지가 없는 가벼운 참여형 콘텐츠에만 제한
- `감사합니다`: 글의 마무리 또는 독자 인사

색상별 역할은 절대 규칙이 아니라 게시물의 정보 구조를 통일하기 위한 기본값이다.

## 3. 썸네일 활용

- 카테고리별 승인 템플릿이 아래 일반 캐릭터 규칙보다 우선한다.
- `BYCHEM 인사이트`, `BYCHEM 솔루션`, `BYCHEM 시리즈` 썸네일은 실제 기업 촬영물 같은 현실적인 산업·연구·설비 사진을 기본으로 한다. 자연스러운 노출·화이트밸런스와 절제된 채도·대비·선명도를 사용하고 HDR, 네온 조명, 과도한 샤프닝, 인공적인 광택과 AI 특유의 부자연스러운 질감을 피한다.
- 위 세 카테고리의 썸네일 제목은 흰색 Pretendard ExtraBold 800, 64pt로 왼쪽 아래에 안전 여백을 두고 배치한다. 제목 외 문구·라벨·숫자·로고·캐릭터는 별도 요청이 없으면 넣지 않는다.
- 사용자가 대표사진 캐릭터를 별도로 요청한 경우에만 캐릭터를 전체 이미지 높이의 약 20~40%로 배치하고 장면 속 행동이 자연스럽게 보이도록 한다.
- 별도 요청으로 캐릭터를 넣을 때도 큰 제목과 핵심 배경을 가리지 않는 모서리 또는 측면에 둔다.
- 제목은 이미지 위에 직접 올리고 띠·박스·구분선을 사용하지 않는다.
- `BYCHEM 인사이트`, `BYCHEM 솔루션`, `BYCHEM 시리즈`는 흰색 Pretendard ExtraBold 800, 64pt를 기본으로 한다. 다른 카테고리는 승인된 카테고리 템플릿을 따른다.
- 같은 카테고리는 폰트, 굵기, 글자 크기, 위치, 줄바꿈, 기본색, 외곽선과 그림자를 동일하게 유지한다.
- 제목 색상은 카테고리 기본색으로 통일하고, 변화가 필요하면 승인된 강조어 한 곳에만 하이라이트를 적용한다.
- 흰 외곽선과 미세한 그림자는 가독성 보조 목적으로만 사용한다.
- 220×220px 축소본에서 제목과 핵심 배경이 알아보이는지 최종 확인한다. 캐릭터를 별도 요청으로 넣은 경우에만 캐릭터 식별성도 확인한다.
- 썸네일로 사용하는 대표사진에는 별도의 캡션이나 이미지 설명 문장을 입력하지 않는다.

## 4. 본문 이미지 활용

- 캐릭터는 설명자·연구자·발표자·점검자 등 주제에 맞는 역할로 다양하게 배치한다.
- 본문 이미지에는 큰 제목을 넣지 않는다.
- 기술 구조, 화학 개념, 흐름도와 핵심 오브젝트가 캐릭터보다 우선한다.
- 본문 정보 이미지마다 목적·구도·캡션·대체텍스트를 별도로 작성한다. 대표사진과 장식용 네이버 스티커는 제외한다.
- 캡션은 네이버 이미지 컴포넌트의 `사진 설명` 입력란에만 넣는다. 같은 문장을 본문 문단으로 붙여 넣지 않는다.
- 이미지 설명은 캐릭터 행동보다 이미지가 전달하는 정보를 형식적이고 구체적으로 작성한다.
- `초록 래미가 점검하는 모습`처럼 캐릭터 자체를 설명하지 않는다. 별도 정보 가치가 없으면 캡션은 비워 둔다.
- 예: `AI 칩의 열이 열전달 접촉부와 콜드플레이트, 냉각유체, 배관, 열교환기를 거쳐 이동하는 경로`
- 개별 이미지마다 ‘주의’ 문구를 반복하지 않고 본문 마지막의 AI 이미지 고지문으로 통일한다.

## 5. 스타일과 색상 운영

- 기본 스타일은 실제 연구실·사무실·산업현장처럼 보이는 밝은 공간과 사실적인 고급 3D CGI·에디토리얼 사진의 조합이다.
- 캐릭터는 제공된 참고 이미지처럼 실제 공간에 자연스럽게 참여하는 3D 마스코트로 표현한다.
- 지나치게 어둡거나 위협적인 산업 사진, 다크 SF, 화재·사고·유해물질 노출 장면은 사용하지 않는다.
- 게시물의 모든 이미지를 동일한 파란색 톤으로 만들지 않는다.
- 이미지별로 웜화이트, 그래파이트, 구리, 청록, 녹색, 주황 등 주제에 맞는 보조색을 달리 사용한다.
- 기술 비교가 우선인 이미지는 캐릭터를 생략하고 사실적인 3분할·클로즈업 구성을 사용할 수 있다.
- 새 이미지를 만든 뒤 대표·본문 전체와 비교한다. 파일명이 달라도 같은 장비, 배경, 카메라 각도와 정보가 반복되면 중복 컷으로 보고 한 장을 제외한다.

## 6. 이미지 생성 프롬프트에 붙이는 공통 문장

```text
Use the provided BYCHEM images as the exact mascot-identity and visual-style references. Preserve the recognizable face, white fleece, tan curled horns, rounded proportions, and the original glasses or goggles, scarf, and glove colors. Place one polished 3D mascot naturally inside a bright realistic workplace, laboratory, office, or industrial setting, performing a role suited to the topic without covering the main technical subject. Match soft commercial photography lighting and realistic materials while keeping the scene clean and approachable. Do not redesign the mascot, combine it with another character, add unapproved text, or portray it as a real employee, product endorsement, hazardous actor, political figure, or sensational subject. Avoid flat illustration, dark sci-fi, threatening industrial imagery, and a uniform all-blue palette.
```

## 7. 게시 전 검수

- [ ] 원본 캐릭터의 얼굴·뿔·색상·소품이 유지되었는가
- [ ] 장식용 스티커와 별도로 래미가 통합된 본문 이미지가 최소 1컷 있는가
- [ ] 한 이미지에 캐릭터가 한 명만 등장하는가
- [ ] 캐릭터가 기술 정보나 제목을 가리지 않는가
- [ ] 캐릭터의 색상과 역할이 앞뒤 이미지에서 반복되지 않는가
- [ ] 이미지마다 보조색·구도·공간 분위기가 구분되는가
- [ ] 스티커가 게시물당 1~2개 이내이며 문맥에 맞게 사용되었는가
- [ ] 스티커 문구와 주변 본문이 불필요하게 반복되지 않는가
- [ ] 썸네일 제목의 한글이 정확하고 220px에서도 읽히는가
- [ ] 본문 이미지에 불필요한 큰 제목이나 에디터 UI 문구가 없는가
- [ ] 이미지 설명이 캐릭터 행동이 아니라 핵심 정보를 형식적으로 설명하는가
- [ ] 캡션이 `사진 설명` 입력란에만 있고 본문에 중복되지 않았는가
- [ ] 설명 가치가 없는 이미지의 캡션을 비워 두었는가
- [ ] 기존 기술 이미지와 새 캐릭터 이미지가 같은 장비·구도·정보를 중복하지 않는가
- [ ] 실제 제품·현장·인물·성과로 오인될 요소가 없는가
- [ ] AI 이미지 고지문이 본문 마지막에 유지되어 있는가
