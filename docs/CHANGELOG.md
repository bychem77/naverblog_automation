## 2026-08-25 · 마스터 프롬프트 1.1

- 승인된 캘린더 종료 후 AI가 다음 달 주제를 선제적으로 제안하도록 명시
- 일반 정보형 검색 콘텐츠는 바이켐과 억지로 연결하지 않도록 명시
- 한 문장 한 가지 정보, 문단당 1~2문장, 내용 전환 시 빈 줄 규칙 강화
- 항목 3개 이상은 목록 또는 체크포인트로 전환
- 이모지를 소제목 중심으로 게시물당 약 3~6개 사용
- 네이버 숫자 목록의 `1., 1.` 반복을 막기 위해 `①~⑤` 또는 `✅` 형식 사용
- 캐릭터 이미지를 대표와 본문 합계 1~2컷 중심으로 조정
- 대표·기술·캐릭터 이미지 사이의 파일 및 유사 구도 중복 금지
- 새 캐릭터 이미지가 기존 기술 이미지와 겹치면 한 장만 유지
- 대표사진 무캡션, 본문 이미지는 기술 중심 캡션 또는 공란 적용
- 캐릭터 이름·색상·행동만 설명하는 캡션 금지
- 같은 카테고리 썸네일의 폰트·크기·위치·색상·효과 통일
- 썸네일 제목은 면적 약 1/3, 배경 위 직접 배치, 색 띠와 큰 박스 금지
- 스티커는 360~420px 또는 본문 폭 35~50%, 게시물당 1~2개 적용
- 가운데 정렬, 비공개 기본 발행, 태그 입력란 사용과 게시 후 UI 문구 검수 유지
