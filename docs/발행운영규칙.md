# 바이켐 네이버 블로그 발행 운영 규칙

## 1. 카테고리 자동 분류

### BYCHEM 뉴스

다음과 같이 바이켐 자체가 소식의 주체인 콘텐츠를 분류한다.

- 사내 소식과 조직 문화
- 행사·전시회·협약·수상·채용
- 언론 보도와 보도자료
- 회사 공지와 공식 활동
- 임직원·사업장·기업 성과 소개

### BYCHEM 인사이트

검색 유입과 산업 이해를 목적으로 하는 미래산업·기술·시장 콘텐츠를 분류한다.

- AI와 AI 데이터센터
- 반도체·HBM·배터리·모빌리티
- 첨단소재와 미래산업
- 산업·기술·시장 트렌드
- 특정 바이켐 제품을 중심으로 하지 않는 전문 정보

### BYCHEM 솔루션

화학 원리와 소재·제품의 쓰임을 실생활 또는 실무 관점에서 설명하는 콘텐츠를 분류한다.

- 생활 속 화학
- 용제·세척제·첨가제 등 화학 소재 기초
- 소재별 특징과 활용 분야
- 현장 체크포인트와 문제 해결 정보
- 안전한 취급·선정·관리 방법
- 일반 화학 정보와 실무 설명을 중심으로 하되, 마지막에 관련 승인 제품을 짧게 연결하는 콘텐츠

### BYCHEM 시리즈

바이켐의 제품 자체가 주제의 중심인 콘텐츠를 분류한다.

- 기존 바이켐 제품 소개 게시물
- 개별 제품·제품군의 용도와 적용 분야
- 승인된 제품 사양·특징·취급 정보
- 승인된 기술자료를 바탕으로 한 제품 선택 안내

## 2. 분류 우선순위

주제가 겹칠 때는 다음 순서로 판단한다.

1. 바이켐의 공식 활동·성과·공지가 중심이면 `BYCHEM 뉴스`
2. 특정 바이켐 제품과 적용 정보가 중심이면 `BYCHEM 시리즈`
3. AI·첨단산업·시장 변화와 기술 전망이 중심이면 `BYCHEM 인사이트`
4. 생활 속 화학·소재 원리·활용법·실무 해결책이 중심이면 `BYCHEM 솔루션`

예시:

- `AI 데이터센터는 왜 뜨거워질까?` → BYCHEM 인사이트
- `자일렌은 어디에 사용될까?` → BYCHEM 솔루션
- `BCS-SS의 특징과 적용 분야` → BYCHEM 시리즈
- `바이켐 전시회 참가 소식` → BYCHEM 뉴스

### BYCHEM 솔루션 마무리의 제품 연결

- 본문은 일반 정보와 실무 내용을 중심으로 유지하고, 마지막 2~4개 짧은 문단에서만 관련 바이켐 제품을 연결한다.
- `기존 소재·공정의 관리점 → 대안의 선택 조건 → 승인된 바이켐 제품 → 적용 확인·문의` 순서로 작성한다.
- 제품명·사양·저독성·친환경성·세정력·대체 가능 범위는 승인된 제품자료나 승인된 기존 `BYCHEM 시리즈` 게시물에서 확인된 내용만 사용한다.
- IPA처럼 독성·인화성 등 관리가 필요한 소재의 특성은 분명히 설명한다. `사용 금지`, `퇴출 추세` 같은 규제·시장 변화만 확인된 범위에서 쓴다.
- 제품의 구체적인 수치나 적용 범위가 확인되지 않은 부분만 `[사내 확인 필요]`로 표시한다.
- 관련 제품이 없는 글에는 브랜드 연결 문단을 억지로 추가하지 않는다.

### 제품 카탈로그 활용

- 바이켐 제품 내용, 제품군, 적용 분야와 관련된 글감은 `references/product_catalog/`의 카탈로그를 우선 확인한다.
- 제품 중심 글은 `BYCHEM 시리즈`, 일반 화학 정보에서 관련 제품을 연결하는 글은 `BYCHEM 솔루션`으로 분류한다.
- 카탈로그에 명시된 제품명·특징·용도·적용 분야만 확인된 범위에서 사용한다.
- 카탈로그에 없는 성능·수치·안전성·친환경성·대체 가능성·고객사·실적·적용 사례는 추정하지 않는다.
- 2023~2024년 제작 카탈로그와 최신 SDS·제품 사양서·법령·사내 승인자료가 다르면 최신 승인자료를 우선한다. 최신 여부나 공개 가능 범위가 불분명하면 `[사내 확인 필요]`로 표시한다.

## 3. 대표사진 카테고리 템플릿

- 대표사진은 `BYCHEM 뉴스`, `BYCHEM 인사이트`, `BYCHEM 솔루션`, `BYCHEM 시리즈`의 카테고리별 고정 템플릿으로 제작한다.
- 같은 카테고리의 대표사진은 다음 항목을 반드시 동일하게 유지한다.
  - 제목 폰트와 굵기
  - 제목 크기와 행간·자간
  - 제목 줄 수 기준과 줄바꿈 방식
  - 제목 위치·정렬·안전 여백
  - 글자색과 하이라이트 색상
  - 외곽선·그림자·반투명 배경 등 가독성 효과
  - 카테고리명·로고가 들어갈 경우 그 위치와 크기
- 게시물마다 변경할 수 있는 요소는 제목 문구, 주제에 맞는 배경 이미지, 필요한 경우 승인된 강조어 한 곳으로 제한한다.
- 배경 이미지는 게시물마다 중복 사용하지 않되, 같은 카테고리에서는 전체적인 구성 체계와 정보 위계를 유지한다.
- 제목은 모바일 썸네일에서도 읽히도록 이미지 면적의 약 1/3을 차지하는 크기로 배치한다.
- 제목을 별도의 색 띠로 이미지와 분리하지 않고 배경 이미지 위에 직접 배치한다. 가독성이 부족할 때만 동일한 템플릿 효과를 적용한다.
- 카테고리별 최초 승인본을 기준 이미지로 저장하고, 이후 임의로 폰트·크기·효과를 바꾸지 않는다. 변경이 필요하면 해당 카테고리 템플릿 전체를 함께 개정한다.
- 본문 이미지는 대표사진용 제목 템플릿을 적용하지 않는다.
- 대표사진에는 별도의 캡션이나 이미지 설명 문장을 입력하지 않는다.

### 카테고리별 템플릿 구분

- `BYCHEM 뉴스`: 뉴스 대표사진 승인 템플릿
- `BYCHEM 인사이트`: 아래 세 카테고리 공통 대표사진 템플릿을 적용한다.
- `BYCHEM 솔루션`: 아래 세 카테고리 공통 대표사진 템플릿을 적용한다. 기존 `2026-08-26 IPA`의 캐릭터·바이켐 블루 좌측 상단 제목 형식은 신규 대표사진의 기본 템플릿으로 사용하지 않는다.
- `BYCHEM 시리즈`: 아래 세 카테고리 공통 대표사진 템플릿을 적용한다.

### 인사이트·솔루션·시리즈 공통 대표사진 템플릿

- 실제 기업이 현장에서 촬영한 듯한 현실적인 산업·연구·설비 사진을 배경으로 사용한다.
- 자연스러운 노출과 화이트밸런스, 절제된 채도·대비·선명도를 유지한다.
- 과도한 HDR, 네온 색감, 과도한 샤프닝, 인공적인 광택과 AI 특유의 부자연스러운 디테일을 피한다.
- 제목은 흰색 Pretendard ExtraBold 800, 70pt로 왼쪽 아래에 안전 여백을 두고 배치한다.
- 제목 외 보조 문구·라벨·숫자·로고·캐릭터는 담당자가 별도로 요청하지 않는 한 넣지 않는다.
- 제목은 배경 사진 위에 직접 배치하고 색 띠·박스·구분선을 사용하지 않는다.

## 4. 문체와 본문 편집

- 본문 텍스트는 공백 포함 약 2,500자를 기본으로 한다. 제목, 이미지 캡션, URL과 태그는 분량 계산에서 제외한다.
- 글자 수를 늘리기 위해 같은 정의·장점·수치·사례·결론을 다른 표현으로 되풀이하지 않는다.
- 각 소제목은 원리, 차이, 활용, 선택 기준, 적용 조건, 안전처럼 서로 다른 정보 목적을 가져야 한다. 추가 분량은 앞에서 다루지 않은 정보로 보강한다.
- 화학·산업을 잘 아는 친절한 전문가가 비전공자에게 차근차근 설명하는 느낌으로 작성한다.
- 전문성을 유지하되 보고서처럼 딱딱하게 쓰지 않는다. 독자에게 말을 건네는 문장과 생활 속 예시를 적절히 섞는다.
- 한 문장은 가능한 한 짧게 쓴다. 한 문장에 정보가 두 가지 이상 들어가면 나누는 것을 우선한다.
- 한 문단은 1~2문장으로 구성한다. 긴 설명도 3문장을 넘기지 않는다.
- 내용·관점·설명 단계가 바뀌면 반드시 빈 줄을 넣어 문단을 충분히 구분한다.
- 연속된 줄글보다 소제목, 짧은 문단, 목록, 체크포인트, 한 줄 요약을 활용한다.
- 공정·특징·활용 분야·비교 항목이 3개 이상이면 목록 또는 단계형 구성으로 바꾼다.
- 한 문장에는 한 가지 정보를 중심으로 담고, 원인·결과·예외가 몰리면 문장을 나눈다.
- 마침표로 끝나는 완결 문장 뒤에는 Enter 1번을 입력해 다음 문장을 새 문단에서 시작한다. 소수점·약어·URL 안의 마침표는 제외한다.
- 모바일 화면에서 한 덩어리의 긴 줄글처럼 보이면 문장과 문단을 다시 나누고 빈 줄을 추가한다.
- `~해요`, `~인데요`, `~볼게요`를 기본으로 하고 전문 설명에는 `~입니다`, `~합니다`를 자연스럽게 섞는다.
- 공감·호기심·안도감을 주는 표현을 가볍게 더하되 과장, 감탄사 남발, 지나치게 귀여운 말투는 피한다.
- 각 소제목 앞에는 `📌`, `🧪`, `💡`, `🔎`, `😊` 등 문맥에 맞는 작은 텍스트 이모티콘을 1개 붙이고 한 칸 띄운다. 같은 이모티콘의 불필요한 반복을 피한다.
- 본문 전체는 제목·텍스트·이미지·스티커를 포함해 가운데 정렬한다.
- 네이버 숫자 목록을 항목마다 별도 생성하지 않는다. 숫자가 `1., 1.`처럼 반복될 가능성이 있으면 `①~⑤` 또는 `✅` 일반 문단으로 바꾼다.

### 최우선 편집·배치 규칙

- 모든 텍스트와 미디어는 가운데 정렬한다.
- 네이버 게시물 메인 제목은 나눔고딕 32pt로 사용한다.
- 본문은 나눔고딕 16pt·행간 200%, 소제목은 나눔고딕 Bold(굵게) 21pt를 사용한다.
- 모든 소제목 앞에는 바로 앞 요소와 관계없이 빈 줄 3개, 즉 Enter 3번을 적용한다.
- 대표이미지 제목은 흰색 Pretendard ExtraBold 70pt로 고정한다.
- 소제목과 바로 뒤 첫 설명 문단은 하나의 고정 텍스트 그룹이다. 둘 사이에는 빈 문단이나 다른 요소를 넣지 않으며, 같은 소제목에 속한 설명 문단 사이에도 빈 문단을 넣지 않고 연속 문단으로 붙인다.
- 이미지·이모티콘·스티커는 연속 배치하지 않는다. 빈 줄만 사이에 있는 경우도 연속 배치로 판단하고 두 미디어 사이에는 의미 있는 본문을 둔다.
- 미디어 개수는 고정하지 않고 내용 전달에 필요한 만큼 사용한다.
- 래미 스티커·이모티콘 이미지는 기존보다 20% 확대해 긴 변 약 168~198px로 사용하고 일반 본문 설명 이미지 크기는 유지한다.
- 대표이미지·본문 이미지·래미 이모티콘을 포함한 모든 미디어의 위와 아래에는 각각 Enter 2번을 정확히 적용한다.
- 모든 카테고리의 모든 게시물에 정확한 제목 `한줄정리`를 반드시 넣고, 본문에서 이미 설명한 핵심만 1~2개의 짧은 문장으로 요약한다. 새로운 주장·수치·제품 효능이나 미확인 내용은 추가하지 않는다.
- `한줄정리` 제목과 요약 내용 전체를 굵게+기울임으로 적용한다. 제목과 요약 문장 사이, 각 요약 문장 사이에는 빈 문단을 넣지 않는다.
- `함께 읽으면 좋은 글` 영역이 있으면 한줄정리보다 아래에 배치한다. 한줄정리의 마지막 요약 문장 뒤에는 Enter 3번을 적용한 다음 관련 글 제목과 링크를 입력한다.
- 본문 마지막은 `굵게+기울임 한줄정리 및 요약 전체 → Enter 3번 → 함께 읽으면 좋은 글 제목·링크 → Enter 5번 → 본 콘텐츠에 사용된 이미지는 내용의 이해를 돕기 위해 AI로 생성되었습니다.` 순서로 마무리한다. 관련 글이 없으면 한줄정리 뒤 Enter 5번과 AI 이미지 고지문만 적용한다.

### 네이버 스티커 배치

- 게시물 도입부의 첫 인사 앞이나 뒤에는 `안녕하세요` 스티커를 사용할 수 있다.
- 독자의 궁금증을 여는 질문형 구간에는 `궁금해요` 스티커를 사용할 수 있다.
- 연구·기술 설명에는 `연구중`, 체크리스트에는 `꼼꼼하게`, 핵심 요약 뒤에는 `좋아요`, 마무리에는 `감사합니다`를 문맥에 맞게 선택한다.
- 스티커와 이모티콘의 개수는 문맥에 따라 정하되 서로 연속 배치하지 않는다.
- 스티커는 기술 이미지처럼 문서 너비로 확대하지 않는다. 래미 스티커·이모티콘은 긴 변 약 168~198px로 사용한다.
- 스티커 앞뒤에는 빈 줄을 두어 본문과 붙어 보이지 않도록 한다.
- 스티커에 적힌 문구를 바로 옆 본문에서 똑같이 반복하지 않는다.
- `쉿 비밀`은 보안이나 은폐를 연상시킬 수 있으므로 일반 정보형·기업형 게시물에서는 사용하지 않는다.

## 5. 이미지 구성과 캡션

- 대표사진과 본문 이미지의 개수는 내용 전달에 필요한 만큼 정하며, 개수를 기계적으로 제한하거나 채우지 않는다.
- 기본 구성은 대표사진 1컷, 캐릭터 본문 이미지 1컷, 캐릭터 없는 기술 이미지 2컷이다. 대표사진에서 캐릭터를 크게 사용했으면 본문 캐릭터 이미지는 0~1컷으로 줄인다.
- 새 게시물에는 장식용 스티커와 별도로 래미가 기술 장면에 자연스럽게 통합된 본문 이미지가 최소 1컷 있어야 한다. 사용자가 캐릭터 제외를 명시한 경우만 예외로 한다.
- 모든 이미지에 캐릭터를 넣지 않는다. 기술 구조와 핵심 정보가 캐릭터보다 우선한다.
- 동일 파일뿐 아니라 같은 실험실·설비·카메라 각도·안전 점검 장면처럼 유사한 구도도 중복으로 본다.
- 새 캐릭터 이미지가 기존 기술 이미지와 같은 정보를 전달하면 정보 전달력이 높은 한 장만 남긴다.
- 대표사진에는 캡션과 이미지 설명을 입력하지 않는다.
- 본문 이미지 캡션은 기술 구조·작동 원리·공정 흐름처럼 독자에게 필요한 정보를 설명한다.
- 본문 이미지 캡션은 해당 이미지의 `사진 설명` 입력란에만 입력한다. 캡션 문장을 독립된 본문 문단으로 넣지 않고 저장 후 중복 여부를 확인한다.
- 캐릭터 이름, 색상이나 행동만 설명하는 캡션은 사용하지 않는다. 별도 정보 가치가 없으면 비워 둔다.
- 본문 이미지에는 대표사진용 큰 제목 디자인을 사용하지 않는다.
- AI 생성 이미지를 사용한 글은 본문 마지막에 `본 콘텐츠에 사용된 이미지는 내용의 이해를 돕기 위해 AI로 생성되었습니다.`를 한 번 표기한다. 고지문은 가운데 정렬 8pt로 적용하며, 네이버에서 8pt를 선택할 수 없으면 11px(약 8.25pt)를 사용한다.

## 6. 해시태그 입력

- 해시태그는 본문 마지막에 나열하지 않는다.
- 네이버 블로그의 `발행 → 태그 편집` 입력란에만 등록한다.
- 모든 게시물에 바이켐 공통 태그 `#바이켐`, `#페인트시너`, `#산업용세정제`, `#산업용용제`, `#유기용제`를 반드시 포함한다.
- 고정 태그 5개에 카테고리 태그 1~2개와 주제별 태그 2~5개를 더해 게시물당 총 8~12개를 기본으로 한다.
- 메인 키워드, 보조 키워드, 산업 분야, 독자 검색어를 조합한다.
- 같은 의미의 태그를 철자만 바꿔 과도하게 반복하지 않는다.
- 글의 내용과 직접 관련 없는 카테고리·주제 태그는 검색량이 높더라도 넣지 않는다.
- 본문에 남은 `#태그` 조각이 없는지 발행 전 검색한다.

### 태그 구성 순서

1. 전 게시물 고정: `#바이켐` `#페인트시너` `#산업용세정제` `#산업용용제` `#유기용제`
2. 카테고리별 선택:
   - BYCHEM 뉴스: `#바이켐소식` `#기업소식`; 실제 보도자료일 때만 `#보도자료`
   - BYCHEM 인사이트: `#산업인사이트` `#첨단산업` `#첨단소재`; AI 주제일 때 `#AI인사이트`
   - BYCHEM 솔루션: `#생활속화학` `#화학상식` `#용제`; 해당 글일 때 `#산업용화학`, `#화학이야기`, `#산업용세정제` 등을 선택
   - BYCHEM 시리즈: `#바이켐제품` `#제품소개`; 실제 제품명과 승인된 적용 분야 태그를 추가
3. 메인 주제 태그 1~2개
4. 세부 기술·소재·검색 의도 태그 2~4개

## 7. 발행 전 확인

- [ ] 본문 텍스트가 공백 포함 약 2,500자인가
- [ ] 같은 정보·수치·사례·결론이 표현만 바뀐 채 반복되지 않고, 각 소제목이 서로 다른 정보를 전달하는가
- [ ] 제목·본문·이미지·이미지 설명이 모두 가운데 정렬되었는가
- [ ] 네이버 게시물 메인 제목이 나눔고딕 32pt인가
- [ ] 모든 이미지·이모티콘 위아래에 Enter 2번이 정확히 적용되었는가
- [ ] 대표 이미지가 지정되었는가
- [ ] 대표사진의 폰트·크기·위치·색상·효과가 해당 카테고리 승인 템플릿과 일치하는가
- [ ] 대표사진에 불필요한 캡션이나 이미지 설명이 입력되지 않았는가
- [ ] 본문 이미지에 대표사진용 제목 디자인이 들어가지 않았는가
- [ ] 동일 파일 또는 유사한 설비·구도·메시지의 이미지가 중복되지 않았는가
- [ ] 본문 이미지 캡션이 캐릭터 행동이 아닌 기술 정보를 설명하는가
- [ ] 캡션이 `사진 설명` 입력란에만 있고 본문에 중복되지 않았는가
- [ ] 장식용 스티커와 별도로 래미가 통합된 본문 이미지가 최소 1컷 있는가

- [ ] 한 문단이 1~2문장 중심이며 내용이 바뀌는 지점마다 빈 줄이 있는가

- [ ] 긴 줄글을 목록·체크포인트·소제목으로 적절히 나눴는가
- [ ] 각 소제목 앞에 문맥에 맞는 작은 텍스트 이모티콘이 1개 있는가
- [ ] 소제목과 첫 설명 문단 사이, 같은 소제목의 설명 문단 사이에 빈 문단이나 다른 요소가 없는가
- [ ] 이미지·이모티콘·스티커가 연속 배치되지 않고 두 미디어 사이에 의미 있는 본문이 있는가
- [ ] 모든 소제목이 나눔고딕 Bold(굵게) 21pt이며 앞에 Enter 3번이 적용되었는가
- [ ] 래미 스티커·이모티콘이 긴 변 약 168~198px로 적용되었는가
- [ ] 모든 게시물에 정확한 제목 `한줄정리`와 본문 핵심을 요약한 1~2문장이 있으며 새로운 주장이나 미확인 내용이 없는가
- [ ] `한줄정리` 제목과 요약 전체가 굵게+기울임이며 내부에 빈 문단이 없는가
- [ ] `함께 읽으면 좋은 글`이 한줄정리보다 아래에 있고, 한줄정리 마지막 문장 뒤에 Enter 3번이 적용되었는가
- [ ] 본문에 에디터 UI 문구가 남지 않았는가
