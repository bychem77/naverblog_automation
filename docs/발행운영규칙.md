# 바이켐 블로그 발행 운영 안내

> 이 문서는 담당자가 작업 흐름을 이해하기 위한 안내서입니다. 콘텐츠 결과를 결정하는 문체, 분량, 카테고리, 제품 연결, 이미지, 스티커, 폰트, 간격, 태그와 검수 기준은 오직 `prompts/BYCHEM_NAVERBLOG_MASTER_PROMPT.md`에서 확인합니다.

## 운영 원칙

1. 고정 콘텐츠 캘린더는 사용하지 않습니다.
2. 매 회차 최근 화제성, 검색 유입 가치, 카테고리 균형과 기존 글 중복을 확인해 주제를 정합니다.
3. 사용자가 특정 주제를 지정하면 해당 요청을 우선합니다.
4. 제품 내용은 승인된 제품자료 범위 안에서만 사용합니다.
5. 담당자가 공개를 명시적으로 승인하기 전에는 비공개로 게시합니다.

## 카테고리 선택

카테고리 정의와 우선순위는 마스터 프롬프트의 `3. 카테고리 분류`를 그대로 적용합니다. 이 문서에 별도의 분류표를 복사하지 않습니다.

## 제작과 게시

작업 단계는 `docs/WORKFLOW.md`를 따릅니다. 정확한 편집값과 발행 전 체크리스트는 마스터 프롬프트의 최신 버전을 그대로 적용하며, 기억이나 과거 게시물을 기준으로 재구성하지 않습니다.

## 제품자료 사용

제품 관련 글을 작성할 때는 `references/product_catalog/README.md`에서 대상 자료를 찾습니다. 카탈로그보다 최신인 SDS, 제품 사양서, 법령 또는 사내 승인자료가 있으면 최신 승인자료를 우선합니다.

## 문서 해석 금지 범위

- `examples/`는 당시 결과물이며 현재 규칙이 아닙니다.
- `docs/CHANGELOG.md`는 과거 변경기록이며 현재 규칙이 아닙니다.
- 카드뉴스 결과물, 기존 게시물과 이메일은 스타일 참고자료일 뿐 마스터 프롬프트를 변경하지 않습니다.
