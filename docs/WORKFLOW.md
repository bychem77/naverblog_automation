# 운영 워크플로

## 1. 월간 기획

통계, 기존 게시물, 계절성, 검색 의도와 콘텐츠 중복을 확인해 월간 캘린더를 제안한다. 회사 자료가 없는 기간에는 일반 정보형 주제를 우선한다.

## 2. 주제 승인

담당자는 제목·카테고리·발행 주차를 승인하거나 수정한다. 이 단계 이후에 본문과 이미지를 제작한다.

## 3. 조사와 사실 검수

핵심 질문과 키워드를 정한 뒤 공식 원자료를 수집한다. 수치·법령·안전·제품 주장은 출처와 문장 단위로 연결한다.

## 4. 원고 작성

마스터 프롬프트의 문체와 네이버 편집 규칙에 따라 짧은 문장과 문단으로 작성한다. 검색 키워드는 자연스럽게 사용하며 반복 삽입하지 않는다.

## 5. 이미지 제작

대표사진과 본문 이미지의 목적이 겹치지 않게 기획한다. 캐릭터 원본을 참조하고, 게시물 내부와 기존 게시물 사이의 중복 구도를 확인한다.

## 6. 담당자 승인

원고, 이미지, 출처, 카테고리와 태그를 한 묶음으로 전달한다. 회사 관련 미확인 항목은 `[사내 확인 필요]` 상태로 남긴다.

## 7. 네이버 입력

로그인된 브라우저에서 제목, 본문, 이미지와 스티커를 가운데 정렬로 입력한다. 해시태그는 발행 설정의 태그 입력란에 등록한다.

## 8. 비공개 저장과 게시 후 검수

기본값은 비공개다. 저장 후 실제 게시물 화면에서 다음을 다시 확인한다.

- 비공개 표시
- 올바른 카테고리와 태그
- 대표 및 본문 이미지 순서
- 중복 이미지 없음
- `1., 1.` 형태의 목록 번호 오류 없음
- `대표사진 삭제`, `AI 활용 설정`, `사진 설명을 입력하세요.` 노출 없음
- AI 이미지 고지문 존재

## 9. 공개 발행

담당자가 공개를 명시적으로 승인한 경우에만 공개 설정으로 변경한다.
