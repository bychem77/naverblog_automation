# 운영 워크플로

## 1. 월간 기획

통계, 기존 게시물, 계절성, 검색 의도와 콘텐츠 중복을 확인해 월간 캘린더를 제안한다. 회사 자료가 없는 기간에는 일반 정보형 주제를 우선한다.

승인된 캘린더 기간에는 정해진 주제를 우선한다. 캘린더 기간이 끝나면 AI가 다음 달 주제를 먼저 제안한다.

## 2. 주제 승인

담당자는 제목·카테고리·발행 주차를 승인하거나 수정한다. 이 단계 이후에 본문과 이미지를 제작한다.

## 3. 조사와 사실 확인

핵심 질문과 키워드를 정한 뒤 공식 원자료로 수치·법령·안전·제품 내용을 확인한다.

## 4. 원고 작성

마스터 프롬프트의 문체와 네이버 편집 규칙에 따라 본문 텍스트를 공백 포함 약 2,500자로 작성한다. 제목, 이미지 캡션, URL과 태그는 분량에서 제외한다. 짧은 문장과 문단을 사용하고 검색 키워드는 자연스럽게 배치한다. 같은 정의·수치·사례·결론을 표현만 바꿔 반복하지 않으며, 추가 분량은 아직 다루지 않은 원리·비교·활용·적용 조건·안전 정보로 보강한다.

## 5. 이미지 제작

대표사진과 본문 이미지의 목적이 겹치지 않게 기획한다. 캐릭터 원본을 참조하고, 게시물 내부와 기존 게시물 사이의 중복 구도를 확인한다.

새 캐릭터 이미지가 기존 기술 이미지와 같은 장비·안전 점검·정보를 반복하면 두 장을 함께 사용하지 않는다. 새 게시물에는 스티커와 별도로 래미가 기술 장면에 통합된 본문 이미지가 최소 1컷 있어야 한다. 본문 캡션은 기술 정보를 설명하고, 정보 가치가 없으면 비워 둔다. 캡션은 반드시 이미지 컴포넌트의 `사진 설명` 입력란에만 넣고 본문 문단으로 중복하지 않는다.

## 6. 담당자 승인

원고, 이미지, 카테고리와 태그를 한 묶음으로 전달한다. 회사 관련 미확인 항목은 `[사내 확인 필요]` 상태로 남긴다.

## 7. 네이버 입력

로그인된 브라우저에서 제목, 본문, 이미지와 스티커를 가운데 정렬로 입력한다. 해시태그는 발행 설정의 태그 입력란에 등록한다.

각 소제목 앞에는 문맥에 맞는 작은 텍스트 이모티콘을 1개 붙인다. 소제목과 바로 뒤 첫 설명 문단은 하나의 고정 텍스트 그룹으로 붙여 두며 그 사이에는 어떤 요소도 넣지 않는다. 이미지·이모티콘·스티커는 연속 배치하지 않고 두 미디어 사이에 의미 있는 본문을 둔다. 미디어 개수는 고정하지 않는다.

## 8. 비공개 저장과 게시 후 검수

게시 전에는 네이버 게시물 메인 제목 나눔고딕 32pt, 본문 나눔고딕 16pt·행간 200%, 소제목 나눔고딕 Bold(굵게) 21pt, 대표이미지 흰색 Pretendard ExtraBold 70pt를 확인한다. 마침표로 끝난 완결 문장 뒤에는 Enter 1번을 적용해 다음 문장을 새 문단에서 시작한다. 모든 소제목 앞에는 Enter 3번을 적용한다. 래미 스티커·이모티콘 이미지는 기존보다 20% 확대해 긴 변 약 168~198px로 사용한다. 대표이미지·본문 이미지·래미 이모티콘을 포함한 모든 미디어의 위와 아래에는 각각 Enter 2번을 정확히 적용한다. 모든 게시물에는 본문 핵심만 담은 `한줄정리` 1~2문장을 반드시 넣고, 제목과 요약 내용 전체는 굵게+기울임으로 적용한다. `함께 읽으면 좋은 글`이 있으면 한줄정리 아래에 배치하고, 마지막 요약 문장 뒤에 Enter 3번을 적용한다. 본문 마지막은 `굵게+기울임 한줄정리 및 요약 전체 → Enter 3번 → 함께 읽으면 좋은 글 제목·링크 → Enter 5번 → 본 콘텐츠에 사용된 이미지는 내용의 이해를 돕기 위해 AI로 생성되었습니다.` 순서로 구성하며, 요약에는 본문에 없는 새로운 주장·수치·제품 효능이나 미확인 내용을 추가하지 않는다. 관련 글이 없으면 한줄정리 뒤 Enter 5번과 AI 이미지 고지문으로 끝낸다.

기본값은 비공개다. 저장 후 실제 게시물 화면에서 다음을 다시 확인한다.

- 비공개 표시
- 올바른 카테고리와 태그
- 대표 및 본문 이미지 순서
- 네이버 게시물 메인 제목 나눔고딕 32pt
- 모든 이미지·이모티콘 위아래 Enter 2번
- 각 소제목 앞 작은 텍스트 이모티콘
- 소제목과 첫 설명 문단 사이에 다른 요소 없음
- 이미지·이모티콘·스티커의 연속 배치 없음
- 모든 소제목 나눔고딕 Bold(굵게) 21pt 및 앞 Enter 3번
- 래미 스티커·이모티콘 긴 변 약 168~198px
- 모든 게시물에 정확한 제목 `한줄정리`와 본문 핵심 요약 1~2문장 존재
- `한줄정리` 제목과 요약 전체 굵게+기울임
- `함께 읽으면 좋은 글`이 한줄정리 아래에 있고 마지막 요약 문장 뒤 Enter 3번
- 중복 이미지 없음
- 파일은 달라도 동일한 설비·구도·메시지를 반복하는 유사 이미지 없음
- `1., 1.` 형태의 목록 번호 오류 없음
- `대표사진 삭제`, `AI 활용 설정`, `사진 설명을 입력하세요.` 노출 없음
- 대표사진 캡션 없음, 본문 이미지는 기술 중심 캡션 또는 무캡션
- 마침표로 끝난 완결 문장마다 다음 문장이 새 문단에서 시작함
- 본문 캡션은 `사진 설명` 입력란에만 존재하고 본문 문단에는 중복 없음
- 장식용 스티커와 별도로 래미가 통합된 본문 이미지 최소 1컷
- AI 이미지 고지문 가운데 정렬 8pt(네이버 최소 11px 상당), 본문 행간 200%

## 9. 공개 발행

담당자가 공개를 명시적으로 승인한 경우에만 공개 설정으로 변경한다.
