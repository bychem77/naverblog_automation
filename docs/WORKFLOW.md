# 운영 워크플로

> 이 문서는 작업 순서만 정의합니다. 콘텐츠 결과물의 모든 수치·문체·서식·이미지·스티커·태그 기준은 `prompts/BYCHEM_NAVERBLOG_MASTER_PROMPT.md`의 최신 버전만 적용합니다.

## 1. 시작 전 동기화

GitHub 최신 내용을 반영하고 `scripts/check_prompt_consistency.sh`를 실행합니다. 검사가 실패하면 제작을 시작하지 않습니다.

## 2. 주제 선정

기존 발행 기록과 초안을 검색해 중복을 확인합니다. 고정 캘린더 없이 최신 동향, 검색 가치와 카테고리 균형을 보고 주제를 정하되, 사용자가 지정한 주제가 있으면 우선합니다.

## 3. 조사와 자료 확인

최신성이 필요한 사실은 공식 원자료로 확인합니다. 회사·제품 내용은 승인 자료만 사용하고 확인되지 않은 부분은 마스터 프롬프트의 처리 기준을 적용합니다.

## 4. 원고와 이미지 제작

마스터 프롬프트의 현재 버전으로 원고, 대표사진, 본문 이미지, 스티커, 캡션, 태그를 한 묶음으로 제작합니다. 이미지 생성 시에만 `prompts/이미지생성_캐릭터활용_프롬프트.md`를 추가로 읽습니다.

## 5. 자체 검수

마스터 프롬프트의 `최종 검수`를 빠짐없이 확인합니다. 이전 게시물의 서식이나 예전 변경기록을 현재 기준으로 사용하지 않습니다.

## 6. 네이버 비공개 게시

로그인된 브라우저에서 알맞은 카테고리와 태그를 적용해 비공개로 게시합니다. 저장 후 실제 게시물 화면을 다시 열어 배치, 이미지, 캡션, 에디터 UI 문구와 공개 상태를 확인합니다.

## 7. 카드뉴스와 검수 전달

카드뉴스는 블로그 원고를 바탕으로 별도 제작하고, 비공개 게시 링크와 함께 담당자에게 전달합니다. 예약 실행의 이메일 형식과 오류 처리는 `automations/BYCHEM_BLOG_AUTOMATION_PROMPT.md`를 따릅니다.

## 8. 공개 전환

담당자가 명시적으로 승인한 경우에만 공개로 전환합니다.
