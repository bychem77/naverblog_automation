# 바이켐 블로그·카드뉴스 예약 실행 프롬프트

이 파일은 예약 실행의 순서와 외부 전달만 정의한다. 원고, 카테고리, 문체, 편집, 이미지, 스티커, 캡션과 태그는 실행 시점의 `prompts/BYCHEM_NAVERBLOG_MASTER_PROMPT.md`를 전부 읽고 그대로 적용한다. 이 파일의 기억이나 과거 실행 결과로 콘텐츠 규칙을 보완하지 않는다.

## 실행 순서

1. 저장소 최신 내용을 반영한다.
2. `scripts/check_prompt_consistency.sh`를 실행한다. 실패하면 제작·게시·메일 발송을 중단하고 충돌 내용을 알린다.
3. 마스터 프롬프트를 전부 읽는다. 이미지 생성 시에만 이미지 보조 프롬프트를 추가로 읽는다.
4. 기존 발행 기록과 초안을 검색해 중복을 제외한다.
5. 고정 캘린더 없이 최근 화제성, 검색 가치와 카테고리 균형을 바탕으로 주제를 정한다. 사용자가 해당 회차의 주제를 지정했다면 우선한다.
6. 공식 원자료와 필요한 승인 제품자료를 확인해 글과 이미지를 제작한다.
7. 마스터 프롬프트의 최종 검수를 통과한 결과만 네이버에 비공개로 게시한다.
8. 같은 내용을 바탕으로 카드뉴스 PNG를 제작한다. 표지 배경과 제목 처리 기준은 마스터 프롬프트를 따른다.
9. 비공개 게시에 성공한 경우에만 `templates/review_email.html`을 사용한 HTML 검수 메일을 로컬 설정의 검토자에게 보낸다. 카드뉴스 PNG를 첨부한다.
10. 원고·이미지·카드뉴스·발행 기록을 저장하고 게시물 링크, 파일 위치와 메일 결과를 보고한다.

## 실행 권한과 오류 처리

- 등록된 예약 회차의 비공개 게시와 검수 이메일 발송은 사전 승인된 작업이므로 다시 묻지 않는다.
- 네이버 로그인 세션이 유효하면 재사용한다. 만료되면 제작물까지 저장하고 게시와 메일만 보류한다.
- 이메일은 HTML 템플릿이 실제 서식으로 렌더링됐는지 확인한 뒤 한 번만 보낸다. 실패 시 자동 재발송하지 않는다.
- 로그인 정보, 쿠키, 토큰, 인증 코드와 수신자 주소는 GitHub, 원고와 로그에 기록하지 않는다.
- 정치적·선정적·논란성 주제는 선정하지 않는다.
