# 바이켐 블로그·카드뉴스 예약 실행 프롬프트

매주 화요일과 목요일 오전 9시(Asia/Seoul)에 바이켐 네이버 블로그 게시물 1건을 완성하고, 네이버에 비공개로 게시하고, 카드뉴스 PNG를 생성하고, 로컬 설정에 등록된 검토자에게 검수 이메일을 보낸다. 이 예약 실행마다 비공개 게시와 검수 이메일 발송은 사전 승인된 작업이므로 실행할 때마다 다시 묻지 않는다.

## 작업 기준

1. 저장소의 `AGENTS.md`에 지정된 순서대로 최신 마스터 프롬프트, 발행 운영 규칙, 이미지 규칙, `docs/WORKFLOW.md`, 기존 발행 기록과 제품 카탈로그를 읽고 적용한다.
2. `scripts/check_prompt_consistency.sh`를 실행한다. 규칙 충돌이 발견되면 게시 전에 정리한다.
3. 고정 콘텐츠 캘린더는 사용하지 않는다. 생활 속 화학·첨단소재·AI·산업 트렌드·자원순환·폐액 재활용 범위에서 최근 화제성, 검색 유입 가치, 카테고리 균형과 기존 게시물 중복 여부를 확인해 매 회차 주제를 자율 선정한다. 사용자가 해당 회차의 특정 주제를 요청하면 그 주제를 우선한다.
4. 이미 발행했거나 초안이 존재하는 주제는 다시 선정하지 않는다.
5. 사실·수치·안전·법령 내용은 최신 공식 원자료로 확인한다. 승인 제품자료에 없는 바이켐 제품 정보나 성능은 만들지 않는다.

## 원고·이미지·카드뉴스

- 최신 BYCHEM 문체와 편집 규칙을 적용한다. 짧은 문장, 충분한 문단 간격, 적절한 텍스트 이모지, 가운데 정렬, 지정 글꼴과 크기, 한줄정리와 필요한 AI 이미지 고지문을 포함한다.
- 사용자가 스티커 제외를 명시하지 않았다면 승인된 네이버 스티커를 최소 1개, 최대 2개 실제로 삽입한다. 기본값은 도입부의 `안녕하세요` 스티커 1개다. 문맥에 따라 `궁금해요`, `연구중`, `꼼꼼하게`, `좋아요`, `감사합니다`로 바꿀 수 있다.
- 승인 스티커 원본을 찾지 못하면 새로 만들거나 생략하지 말고 게시를 보류한 뒤 필요한 파일을 알린다.
- 이미지는 대표사진 1장, 래미 캐릭터가 자연스럽게 들어간 본문 이미지 1장, 설명 가치가 있을 때 캐릭터 없는 기술 이미지 또는 인포그래픽 1장을 기본으로 한다. 이미지와 구도는 게시물 안팎에서 중복하지 않는다.
- 카드뉴스는 모바일 가독성 중심의 PNG 세트로 제작한다. 첫 장은 제목·문구·로고·라벨이 없는 카드뉴스 전용 4:5 `cover_background`를 사용한다. 제목은 템플릿에서 정확히 한 번만 합성하고 시각 검수한다.

## 비공개 게시

- 해당 컴퓨터의 Codex 인앱 브라우저에 보관된 네이버 로그인 세션을 우선 재사용한다.
- 세션이 유효하면 알맞은 카테고리와 태그를 적용해 반드시 비공개로 게시한다. 공개 발행은 하지 않는다.
- 쿠키, 세션 토큰, 아이디, 비밀번호와 인증 코드를 출력하거나 GitHub에 저장하지 않는다.
- 세션이 만료됐거나 재인증이 필요하면 원고·이미지·카드뉴스까지 완성해 저장하고 게시와 이메일을 보류한 뒤 로그인 필요 사실을 알린다.

## 검수 이메일

- 비공개 게시에 성공하면 `automations/local.settings.yaml`에 등록된 검토자에게 이메일을 보낸다.
- 제목은 `[바이켐 블로그 검수 요청] {게시물 제목} 비공개 게시 완료` 형식으로 작성한다.
- 본문은 `templates/review_email.html`의 자리표시자를 실제 게시물 정보로 치환해 HTML로 전송한다. 일반 텍스트 메일로 대체하지 않는다.
- 발송 직전에 남색 머리글, 게시 정보 상자, 초록색 한줄정리 상자와 `비공개 게시물 확인하기` 버튼이 실제 작성 화면에 렌더링됐는지 확인한다.
- 게시물 제목, 카테고리, 게시 상태, 핵심 원고 내용, 한줄정리와 네이버 비공개 링크를 포함하고 카드뉴스 PNG 전체를 첨부한다.
- 이메일 전송에 실패하면 중복 발송하지 말고 실패 원인과 필요한 조치를 알린다.

## 저장과 완료 보고

- 원고·대표사진·본문 이미지·카드뉴스를 `examples/YYYY-MM-DD_주제_상태/`에 저장하고 발행 기록을 갱신한다.
- 완료 후 현재 Codex 작업에 게시물 제목, 카테고리, 비공개 링크, 카드뉴스 PNG 폴더, 이메일 수신자와 발송 결과를 남긴다.
- 정치적·선정적·논란성 소재와 문구·이미지는 사용하지 않는다.
