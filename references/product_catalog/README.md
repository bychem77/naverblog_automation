# 바이켐 제품 카탈로그 참고자료

2026-09-02에 전달받은 `홍보자료시안최종본.zip`에서 중복 파일과 macOS 메타데이터를 제외하고 정리한 바이켐 제품·홍보 자료입니다.

## 포함 자료

- `BYCHEM.pdf`: 바이켐 종합 자료
- `바이켐-12p 국문.pdf`: 국문 종합 카탈로그
- `바이켐-12p 영문.pdf`: 영문 종합 카탈로그
- `BCS-3000.pdf`, `BCS-3000(EN).pdf`, `BCS-3000.hwp`
- `BCS-5000.pdf`, `BCS-5000(EN).pdf`
- `BCS-NEW1000.pdf`, `BCS-NEW1000(EN).pdf`
- `바이켐-양면 BCS-최종수정.pdf`
- `바이켐-실사7종-최종수정.pdf`
- `바이켐-아크릴판넬(2400x1200)-최종수정.pdf`

## 블로그 작성 시 사용 원칙

1. 바이켐 제품 내용, 적용 분야, 제품군과 연관된 블로그 글감을 찾을 때 이 폴더를 우선 확인한다.
2. 카탈로그에 적힌 제품명·특징·용도·적용 분야만 확인된 범위에서 사용한다.
3. 카탈로그 문구를 그대로 길게 복사하지 않고, 바이켐 블로그 문체에 맞게 쉽게 풀어 쓴다.
4. 카탈로그에 없는 성능, 수치, 안전성, 친환경성, 대체 가능성, 고객사, 실적과 적용 사례를 추정하지 않는다.
5. 이 폴더에는 2023~2024년 제작 자료가 포함되어 있다. 최신 SDS, 제품 사양서, 법령 또는 사내 승인자료와 내용이 다르면 최신 승인자료를 우선한다.
6. 최신 여부나 공개 가능 범위가 불분명하면 `[사내 확인 필요]`로 표시한다.
7. 제품 중심 글은 `BYCHEM 시리즈`, 일반 화학 정보에서 관련 제품을 연결하는 글은 `BYCHEM 솔루션`으로 분류한다.

## 중복 정리

원본 압축파일의 `2023 카달로그` 폴더에는 상위 폴더와 내용이 같은 PDF가 포함되어 있었습니다. 저장소 용량과 AI 검색 중복을 줄이기 위해 동일 해시의 중복본은 한 번만 보관합니다.
